
# پروژه نوبت دهی دکتر

در این پروژه موجودیت‌های زیر را داریم :
دکتر ، زمان کاری دکتر ، بیمار و نوبت

## نحوه نصب

به مسیر زیر رفته :
<br>
web api > MS.WebAPI > appSettings.json
بخش connention string را تغییر می‌دهیم به مقدار دلخواه
سپس به مسیر زیر رفته :
Infrastructure > MS.Infrastructure.EF
و پوشه migration را جذف می‌کنیم
سپس در همین پروژه دستورات add-migration و update-database را اجرا می‌کنیم تا database در sql server نصب شود

پروژه آماده است

## مسنتند سازی

مستند سازی این پروژه توسط swagger UI انجام شده است و به راحتی می‌توان از آن استفاده کرد کافی است پروژه را اجرا کرده تا به صفحه swagger UI منتقل شویم
